# Golden Pipeline

This repository will become a small, reusable demonstration of a secure GitHub Actions pipeline that validates a fixture application, reports findings, and progressively enforces quality and security controls.

## Adopt the workflow

Pin the reusable workflow to a full commit SHA:

```yaml
jobs:
  golden-pipeline:
    uses: ASDFGHJKLZXC123/golden-pipeline/.github/workflows/golden-pipeline.yml@<FULL_SHA> # v1.0.1
```
